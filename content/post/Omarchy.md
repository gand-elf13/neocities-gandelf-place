My main computer is now running omarchy, and i don't think i'll ever change that again.

## Omarchy ?

Omarchy is an opinionated…\
Yh f that\
Omarchy is first of all Linux, the very scary thing that cool guys (or ladies) use.\
More precisely it’s ArchLinux the very cool thing edgy fourth grader and senior dev (allegedly) use. It’s reputed as the most hardcore Linux experience, by people with no experience in Linux.\
It’s using Wayland and this is the subject of very heated discussions.\
And the Desktop Environment is Hyprland, which is… idk on 9b people hated it, but like, they where morons.

Have you understood everything ? Yh as I thought gonna make a [Linux](Linux) glossary one day.

So, Omarchy is a flavor of Linux, which is designed to have a workflow independent of mouse.\
It’s not completely the case, but I can write code and publish this website without touching it (I am not yet a pro) so it’s quite effective.

This works because unlike on microslop software, by default windows are not floating around, they snap perfectly, taking all of the space they can, and instead of alt-tabbing like a maniac, there are multiple workspace I can switch to with a keybind (Win+number)\
Launching application is done with a dedicated keybind for stuff I use everyday and the rest gets a tiny launcher I can summon in an instant.

Well this is what hyprland does, and it’s a beautiful piece of software, I was even using it just before switching to omarchy.

Because like Arch, Hyprland doesn’t comme preconfigured, it comes bare, with only the core functionalities in place and it’s quite hard to tune it in a way that feels familiar and welcoming.\
So what one usually does is that it downloads someone else’s rice (configs) and just use those.\
But finding a good rice, that does everything you want, is themed like you want, is updated, is using software you like. That’s very hard.\
Also installing a rice can prove somewhat challenging.

That’s where omarchy comes, it’s essentially a rice, but a very big one. That you install directly as an OS, instead of doing everything manually.

Omarchy made the difficult choices for you, it’s a tuff pill to swallow, and it comes preloaded with a lot of slop (thank god they added a button to remove everything)\
But it made reasonable choices, choices that if you’re new to Linux, you probably dont care and overall, is extremely usable out of the box.

Omarchy is the just works of this small niche that are tiling display managers.

Finally it’s still Hyprland and arch, you have the knowledge or the will to learn, you can ABSOLUTELY modify to your needs. And it’s heavily encouraged.

Also, why arch ? We can have Hyprland somewhere else…\
Arch is king,\
like really, you need a stable internet connection because the update cycle is as short as possible (I manage to live with one update every week)\
But oh boy is it customizable, you can do everything with a bit of digging, it’s a lot of fun and every software you ever need is available with yay. Updating your whole system, like **everything**, is super easy.\
Contrary to more streamlined distro you don’t get to wait decades to get the update of KDE or a modern version of thunderbird.\
Arch is king

Omarchy got a big freakin update,\
Omarchy Quattro, isn’t a fancy rice anymore, I can confidently say it’s better.

So what changed ? If you never used it nor know much about Linux, nothing you will notice, but under the hood…

Omarchy adopted quickshell it’s basically a framework that allows for the creation of a complete DE, you can make pretty much whatever widget bar dock panel you want, it replace all the separate programs that handled the many moving parts of omarchy, and creates a fully customizable centralized system for all you DE features (desktop features = not the apps like Firefox or file manager).\
Plus a system of plugin and a marketplace to share them ! For tray icons, calendars etc… the DE becomes fully customizable with so much ease. Adding, disabling, removing feature can be done in seconds.

Well that’s omarchy ! The fancy distro that I just love. Maybe one day, I’ll make my own arch-hyprland-quickshell config, but I’m not even sure I need it.
